# Unit Net Cap

Лёгкая утилита на чистом Python 3 (без внешних зависимостей) для учёта и ограничения месячного сетевого трафика служб `systemd` и Docker-контейнеров на Ubuntu Server.

## Основные возможности

- **Учёт трафика служб `systemd`:** подключает `IPAccounting=yes` через drop-in файл `/etc/systemd/system/<unit>.d/netcap.conf` без изменения оригинальных юнитов.
- **Поддержка Docker-контейнеров:** отслеживает входящий и исходящий трафик отдельных контейнеров (`docker stats --no-stream`), при превышении лимита сохраняет `RestartPolicy`, отключает автозапуск и останавливает контейнер.
- **Защита от перезагрузок и рестартов:** считает дельту между опросами и хранит накопленный расход за месяц в `/var/lib/unit-net-cap/state.json` (атомарная запись через временный файл и `os.replace`).
- **Постоянный контроль блокировки:** если сервис или контейнер с флагом `blocked_by_quota` снова запущен, демон принудительно останавливает его и отключает автозапуск.
- **Автосброс раз в месяц:** обнуляет счётчики в заданный день месяца (по умолчанию `1-е` число) и возвращает в строй только те объекты, которые были заблокированы именно по квоте.
- **Предохранитель:** критичные службы (`ssh.service`, `sshd.service`, `netcap.service`, `systemd-networkd.service`, `networking.service` и др.) защищены от блокировки и скрыты по умолчанию.
- **Три режима работы:** интерактивное меню (`netcap`), CLI-команды (`netcap <команда>`) и фоновый демон (`netcap daemon`).

## Установка и обновление

```bash
curl -fsSL https://raw.githubusercontent.com/InstalerUP/unit-net-cap/main/install.sh | sudo bash
```
